# Run on GitHub (new account)
1. New repo (make it PUBLIC: free unlimited Actions minutes; there are no secrets in the code). Upload all files from the zip (keep .github/workflows/pack.yml).
2. Settings > Secrets and variables > Actions > New secret: GEMINI_API_KEY (optional: SARVAM_API_KEY, ELEVEN_API_KEY, ELEVEN_VOICE).
3. Edit config.json: your handle and page name.
4. Actions > Make GTA pack > Run workflow. Download the "gta-pack" artifact (zip) from the run page. It also runs by itself every day 09:00 IST.
5. Post from your phone. (Auto-posting to Instagram is not set up: it needs a Business account + Meta app review and breaks easily; manual posting is safer for a new page.)
